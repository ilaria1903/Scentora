# Scentora - Enciclopedie despre Parfumuri

Scentora este o platformă dedicată iubitorilor de parfumuri, un site de tip enciclopedie similar cu Fragrantica, care oferă informații detaliate despre parfumuri, mărci, ingrediente, note olfactive și parfumieri. Utilizatorii pot explora parfumuri în funcție de preferințele lor, vizualiza ratinguri și recenzii, și accesa informații educaționale despre parfumerie.

## Funcționalități:
- **Căutare avansată**: Găsește parfumuri în funcție de note, sezon și alte filtre.
- **Descoperă parfumieri**: Explorează profiluri de parfumieri și creațiile lor.
- **Ratinguri și recenzii**: Vizualizează și adaugă recenzii și ratinguri.
- **Informații educaționale**: Află despre ingrediente, note și procesul de creare a parfumurilor.
- **Recomandări sezoniere**: Parfumurile sunt recomandate în funcție de sezon.

## Tehnologii folosite:

### Frontend:
- **HTML5**: Structura paginilor și semantica site-ului.
- **CSS3**: Stilizarea paginilor, utilizând variabile CSS pentru a personaliza tema.
- **JavaScript**: Interactivitate pe pagină, inclusiv filtre, animații și validări.
- **Font Awesome**: Iconuri pentru navigare și butoane.
- **SASS/SCSS**: Preprocesor CSS pentru o structură mai curată și ușor de întreținut.
- **Bootstrap**: Framework pentru crearea unui design responsiv, cu ajutorul grilelor și componentelor UI.
- **EJS**: Template engine folosit pentru generarea dinamică a paginilor HTML în backend.

### Backend:
- **Node.js**: Platformă JavaScript folosită pentru a crea serverul și a manipula cererile HTTP.
- **Express.js**: Framework pentru construirea aplicațiilor web cu Node.js.

### Alte tehnologii:
- **Git & GitHub**: Sistem de control al versiunilor pentru gestionarea și partajarea codului.
- **Postman**: Instrument pentru testarea API-urilor și verificarea cererilor HTTP.
- **Nodemon**: Utilizat pentru a urmări fișierele sursă și pentru a reîncărca automat serverul la modificările acestora.
- **Google Fonts**: Pentru importul fonturilor externe și personalizarea tipografiei pe site.
